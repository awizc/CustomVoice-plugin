# CustomVoice

BetterDiscord용 음성·방송 플러그인과 Windows native 캡처 도우미입니다.
이 배포본의 저장소 및 업데이트 경로는 **awizc/CustomVoice-plugin**이며 공개 저장소로 운영합니다.
기존 작성자 정보와 번들에 포함된 저작권 표시는 유지합니다.

## 설치

[Releases](https://github.com/awizc/CustomVoice-plugin/releases)에서 Windows x64 ZIP을 받습니다.
압축을 **전부** 풀고 Discord를 트레이에서 완전히 종료한 뒤 `Install.cmd`를 실행합니다.
일반 사용자는 Node.js나 .NET을 따로 설치할 필요가 없습니다.
`CustomVoice.plugin.js`와 `CustomVoice.native` 폴더가 함께 필요하며 기존 설정은 유지합니다.

## 1.1.6 공개 저장소 업데이트

- 공개 저장소에서 플러그인과 native를 받을 때 GitHub 토큰을 필수로 요구하던 처리를 제거했습니다. 선택적으로 등록한 토큰은 계속 사용하며, 비공개 저장소에는 권한이 있는 토큰이 필요합니다.
- 이전 native는 토큰을 필수로 요구하므로, 토큰 없이 사용하는 기존 사용자는 1.1.6 전체 ZIP을 한 번 설치해야 합니다. 유효한 토큰을 이미 등록했다면 기존 업데이트 경로로 받을 수 있습니다.
- 이전에 전달한 1.1.5와 구분하고 native 업데이트가 감지되도록 1.1.6으로 배포합니다. 1.1.4 앱별 오디오와 1.1.5 업데이트 수정이 모두 포함됩니다.
- 실행 테스트 없이 배포용 빌드만 진행했습니다.

## 1.1.5 업데이트 안정성 보완

- 플러그인은 시작 후와 1시간마다 자동 확인합니다. 통화·방송 중에는 30초 간격으로 연결 상태만 확인하고, 종료 후 다운로드/적용을 다시 시도합니다. 실패 시 재시도 간격은 1분부터 최대 15분까지 늘어납니다.
- 1.1.5 native와 함께 사용하면 GitHub 커밋이 바뀌지 않았을 때 큰 플러그인 파일을 다시 다운로드하지 않습니다. 통화 때문에 잠깐 보류한 소스는 최대 1분만 보관합니다.
- 다운로드한 JS는 실행하지 않고 문법을 먼저 파싱합니다. 오류가 있으면 현재 파일을 유지합니다. 실제 기록 결과가 다르면 백업으로 복원하며, 플러그인 이름 변경·강제 비활성화/활성화는 하지 않습니다. 문법 검사는 실행 중 발생하는 오류까지 보장하지 않습니다.
- 플러그인을 끄거나 재시작한 뒤 이전 다운로드 결과가 적용되지 않도록 기존 실행 세대 확인을 유지했습니다. 토큰 만료·권한·요청 제한·GitHub 서버 오류 메시지를 구분합니다.
- native 준비 작업과 설치 작업 사이에 다른 Discord 창이 중복 예약할 수 있던 구간을 차단했습니다. 상태 파일 손상과 이전 작업 중단 시에도 새 요청으로 재시도할 수 있습니다.
- 설정창은 설치된 버전, 실제 로드된 버전의 재시작 필요 여부와 배포된 버전을 구분합니다. 과거 설치 기록이 새 버전 안내를 덮어쓰지 않으며, 필요한 native가 아직 정식 배포되지 않았을 때 전체 ZIP 설치를 안내합니다.
- native 대기 상태 조회는 10초 간격으로 줄이고 겹친 요청을 합칩니다. 이전 다운로드 임시 폴더는 활성 작업이 없을 때만 정리하며, 최근 두 개와 최근 7일 자료 및 설치 백업은 유지합니다.
- native 재사용 패키징은 실제 빌드 버전과 메타데이터가 다르면 중단합니다. native 수동 업데이트는 플러그인 JS를 덮어쓰지 않습니다.
- 기존 1.1.4 오디오 수정도 포함됩니다. 전체 개선 적용에는 플러그인/native 1.1.5가 필요합니다. 실행 테스트 없이 배포용 ZIP을 빌드했습니다.

## 1.1.4 앱별 오디오 경로 보완

- 애플리케이션/창을 선택한 공유는 창모드·보더리스 모두 선택한 프로세스와 자식 프로세스의 오디오만 캡처합니다.
- 시스템 루프백은 전체 화면(`screen:`)을 명시적으로 선택한 경우에만 사용합니다. 창 식별 불가·앱 오디오 실패 시에는 시스템 소리로 대체하지 않습니다.
- 오디오를 최신 패킷 하나로 덮어쓰던 처리를 최대 100ms의 순서 있는 큐로 변경하고, 오디오 처리기가 받은 뒤 다음 묶음을 전달합니다.
- 오디오 처리 스레드 준비를 기다리고, 출력이 무음인 연결을 통해 렌더링이 유지되도록 했습니다. 캡처 소리를 로컬 스피커로 재생하지 않습니다.
- 게임 프로세스 종료 감시에 불필요했던 프로세스 핸들 접근을 제거하고 선택 창/PID를 감시합니다. UWP 프레임은 해당 창 내부의 앱 프로세스를 사용합니다.
- 앱의 상위 런처나 다른 프로세스를 임의로 추가하지 않습니다. 다만 같은 프로세스를 공유하는 여러 창/탭의 소리는 프로세스 단위로 묶일 수 있습니다.
- 실패 단계·캡처 프레임 수·오디오 처리 프레임 수는 기존 로그 폴더에 기록합니다. 음성 내용은 파일로 저장하지 않습니다.
- 이 패치는 **송출자 PC의 플러그인과 native를 함께 1.1.4로 교체**해야 모두 적용됩니다. 시청자 업데이트는 이 오디오 수정의 필수 조건이 아닙니다.
- 문제가 발생한 PC의 로그를 받지 못했으며, 요청에 따라 실행 검증·테스트 없이 코드 수정과 배포용 빌드만 진행했습니다.

## 1.1.3 자동 업데이트 복구

- BetterDiscord에서 지원하지 않는 `fs.openSync` 호출 때문에 업데이트 파일 교체가 실패하던 문제를 수정했습니다.
- 지원되는 `writeFileSync`로 기존 파일을 덮어쓰며, 백업과 실패 시 복원 처리를 유지합니다.
- 1.1.2의 썸네일 변경을 포함합니다. native는 기존 1.1.1을 사용합니다.
- 이 오류가 발생하는 기존 설치본은 수정된 플러그인 파일을 한 번 직접 교체해야 합니다. 고장 난 업데이터 자체는 자동으로 복구할 수 없습니다.
- 이번 수정에서는 실행 검증·테스트를 수행하지 않았습니다.

## 1.1.2 첨부본 반영

- 제공된 `CustomVoice.plugin.js`를 개발 및 배포 기준 파일로 반영했습니다.
- 방송 썸네일을 서버 API로 전달하고 로그인한 사용자가 음성채널 접속 없이 조회하는 코드입니다.
- 서버에 `POST /api/v1/screenshare/preview`, `DELETE /api/v1/screenshare/preview`, `GET /api/v1/screenshare/previews/:mediaIdentity` 구현이 필요합니다.
- 미리보기 편집 원본 `native/voice-extras.js`도 첨부본과 동기화했습니다. native 요구 버전은 1.1.1입니다.
- 이번 반영에서는 실행 검증·테스트 및 서버 배포를 수행하지 않았습니다.

## 1.1.0 변경 사항

- 자신과 같은 채널 사용자의 접속·퇴장 효과음.
- 자신의 마이크/헤드셋 음소거 토글 및 방송 시작·종료 효과음. 설정에서 끄거나 볼륨을 조절할 수 있습니다.
- 방송 유저에게 마우스를 올리거나 유저를 클릭하면 썸네일을 표시합니다.
  같은 음성 채널에서 작동하며 송출자와 시청자 모두 1.1.0이 필요합니다.
  실제 시청 구독이나 오디오 재생 없이 요청한 상대에게 작은 JPEG만 전송합니다.
- 창 공유의 소리는 선택 창의 프로세스 및 자식 프로세스만 캡처합니다.
  실패하면 화면만 공유하며 전체 시스템 소리로 대체하지 않습니다.
  같은 프로세스 트리의 여러 창/탭 소리는 함께 포함될 수 있습니다.
  전체 화면 공유에서 소리를 켜면 시스템 소리를 사용합니다.
- 시청 화면에서 마우스가 나가면 채널명/화질 UI를 숨깁니다. 키보드 조작 중에는 접근성을 유지합니다.
- 연결 해제 시 캡처 트랙, 프로세스 오디오, 시청 구독과 재생 요소를 즉시 정리합니다.
- 시작 직후 업데이트를 지연하고 파일을 제자리에서 교체해 BetterDiscord가 플러그인을 삭제된 것으로 처리하는 문제를 방지합니다.

## GitHub 업데이트

native 1.1.6 이상에서 공개 저장소는 토큰 없이 업데이트합니다. 비공개 저장소를 사용할 때에는 저장소 접근 권한과 Contents 읽기 권한의 GitHub 토큰이 필요합니다.
설정의 **GitHub 업데이트 토큰**에서 등록하거나 삭제할 수 있습니다.
토큰은 소스/일반 설정에 저장하지 않고 현재 Windows 사용자용 DPAPI로 암호화해
`%APPDATA%/BetterDiscord/data/CustomVoice/github-token.bin`에 저장합니다.
플러그인 파일은 시작 후와 매시간 자동으로 확인하고 새 버전이 있으면 갱신합니다.
통화·방송 중에는 적용하지 않습니다. native 버전이 오래되어도 플러그인 파일 업데이트는 진행하며 native 업데이트를 안내합니다.
native는 **BetterDiscord 설정 → 플러그인 → CustomVoice 설정 → native 업데이트**를 눌렀을 때만 받습니다.
현재 버전과 새 버전을 따로 표시하며, 새 버전이 있을 때 버튼이 활성화됩니다.
다운로드가 끝나면 Discord를 트레이에서 완전히 종료하세요. native만 자동 적용하므로 기존 플러그인 파일과 설정은 덮어쓰지 않습니다.
종료 후 5초 정도 기다렸다가 다시 실행하세요. 파일이 사용 중이면 더 기다리며 실패 시 설정창에 오류를 표시합니다.
예약은 최대 24시간 유지됩니다. 중단·실패하면 설정에서 새 버전 확인 후 다시 업데이트할 수 있습니다.
처음 이 기능을 사용하는 기존 1.1.0 사용자는 1.1.1 전체 ZIP 설치가 한 번 필요합니다.
다른 사용자에게 전체 ZIP을 전달해 설치할 수 있습니다. 공개 저장소는 토큰 없이 업데이트하며, 비공개로 전환하면 각자의 저장소 권한과 토큰이 필요합니다.

## 개발 및 패키지 생성

개발 PC에는 .NET 9 SDK와 Node.js가 필요합니다.

```powershell
.\package.ps1 -Dotnet dotnet -SkipCapabilityCheck
```

`native/sync-renderer.cjs`가 native 캡처 및 기능 모듈을 배포용 `CustomVoice.plugin.js`에 반영합니다.
`native/plugin-updater.js`, `native/process-audio.js`, `native/voice-extras.js`가 신규 기능의 편집 원본입니다.
생성물은 `dist/CustomVoice-<버전>-windows-x64.zip`입니다.
릴리스를 배포할 때 같은 빌드에서 생성한 `dist/CustomVoice-native.json`도 ZIP과 함께 업로드합니다.
이 파일은 native 버전과 ZIP의 SHA-256을 담습니다. 태그는 `v<플러그인 버전>` 형식이며 정식 최신 릴리스만 사용합니다.
플러그인만 변경한 릴리스에서는 `@nativeVersion`과 native 버전을 유지하고 `-ReuseNativeBuild`로 패키징합니다.
native 변경 시 `@nativeVersion`, host/preload 버전, `NativeUpdate.CurrentVersion`을 함께 올립니다.
이번 변경에서는 배포 파일 생성에 필요한 빌드만 수행하고 테스트·실측·computer-use는 실행하지 않았습니다.
기존 테스트 코드는 참고용으로 포함되어 있습니다.

로그: `%APPDATA%/BetterDiscord/plugins/logs/CustomVoice`.
native 구성과 서드파티 고지는 `native/README.txt`, `native/THIRD-PARTY-NOTICES.txt`, `native/licenses`를 참고하세요.
프로세스 오디오 구현은 Microsoft의 [ApplicationLoopback API 예제](https://github.com/microsoft/Windows-classic-samples/tree/main/Samples/ApplicationLoopback)를 참고했습니다.
